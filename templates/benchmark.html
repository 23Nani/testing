Understanding the Results
Key Metrics Explained:
  • Key Generation Time: Time to create public/private key pair
  • Encryption Time: Time to encrypt the message
  • Decryption Time: Time to decrypt the ciphertext
  • Expansion Ratio: How much larger the ciphertext is compared to plaintext
Security vs Performance Trade-offs:
  • Toy: Fast but insecure - for learning only
  • Medium: Balanced - suitable for demonstrations
  • Strong: Slower but quantum-resistant - production ready
Note: LWE has larger ciphertext sizes compared to traditional encryption, but provides quantum resistance. This is a necessary trade-off for future-proof security.
